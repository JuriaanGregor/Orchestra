Fader

Base

Wraps an AudioFader, which controls the volume of everything wired through it (0 - 3, where 1 is unchanged). The mix buses and Master created by Orchestra:Start are Faders too.

Tween, FadeIn, FadeOut and Mute return a Promise that resolves when the fade completes. Starting another Tween / Set, or destroying the Fader, cancels it instead and leaves the volume where it was. 

music.Fader:FadeOut(2):andThen(function()
	music:Stop()
end)

Mute​

</>

) → Promise--

Resolves when the fade completes, right away with noTween
