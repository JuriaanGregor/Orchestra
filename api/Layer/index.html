Layer

Base

A stream and a Fader, wired together: the main building block for a single sound. Wire the Layer onwards through its Routing, which belongs to its Fader. 

local music = Orchestra.Layer.new(Enums.Stream.Player, speaker, {
	Name = "Music",
	Asset = "rbxassetid://15287092994",
})

music.Routing:WireTo(emitter.In)
music:Play()
