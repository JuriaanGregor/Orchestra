Orchestra

Engine

The Orchestra engine: the module returns this object. Requiring it has no side effects; call Orchestra:Start on the client to build the mixer: 

Listener:<bus> -> MixBus:<bus> -> Master -> MainOut

Each bus in Config.MIX_BUSES gets an AudioListener on the camera, filtered by AudioInteractionGroup. Give an emitter a bus name as its AudioInteractionGroup to send it to that bus.

CAUTION

Set SoundService.DefaultListenerLocation to None in your place. Otherwise Roblox's default listener wires itself into MainOut, and emitters without an AudioInteractionGroup skip the mix buses. Game scripts can't set it.

Functions​

Start​

This item only works when running on the client. Client
</>
Orchestra:Start() → ()

Builds the mixer: MainOut, the Master Fader, and a mix bus + listener for every bus in Config.MIX_BUSES. Errors on the server; warns and does nothing if already started.

AddMix​

</>
Orchestra:AddMix(busName: string) → Fader?

Adds a mix bus: a Fader named MixBus:<busName> in SoundService.Mixes, wired into Master. Warns and returns nothing if the bus already exists. Call Orchestra:AddListener to give it a listener.

AddListener​

This item only works when running on the client. Client
</>
Orchestra:AddListener(
busName: string--

An existing bus, see Orchestra:AddMix

) → AudioListener

Adds an AudioListener on the camera for an existing mix bus, hearing emitters whose AudioInteractionGroup is busName, and wires it into that bus.
